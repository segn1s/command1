# Астросовье — геймифицированный профиль студента

Веб-приложение на HTML/CSS/JS для **Cloudflare Workers**. Студент развивает четыре тематических виртуальных города (**Качалово**, **Фантазерск**, **Любознайка**, **Движняково**) за реальные достижения и обустраивает комнату маскота-совы за совики.

## Структура проекта

- `wrangler.jsonc` — конфигурация Cloudflare Workers (`assets` из `./public` + Worker `src/index.js`).
- `src/index.js` — Cloudflare Worker (генерация и проверка 6-значных кодов каждые 30 секунд, раздача статики).
- `public/index.html` — экраны и модальные окна приложения «Астросовье».
- `public/css/styles.css` — дизайн-система на основе бренд-токенов (`#0059DA`, `#1D1D1D`, `#ECEEF1`, сезонный акцент).
- `public/js/formulas.js` — расчёт `D̂`, `B`, `AP`, `DP`, `G` и лиг (`Bronze Owl` — `Diamond Owl`).
- `public/js/illustrations.js` — динамические SVG-иллюстрации островов, городов и настраиваемой комнаты Совы (цвет стен, свет, мебель, декор, ковёр).
- `public/js/match3.js` — игра «Три в ряд» 7×7 с комбо, усилителями, автоперемешиванием и начислением совиков.
- `public/js/data.js` и `public/js/app.js` — каталоги, состояние, дневник достижений, календарь и рейтинг.

## Локальный запуск и деплой

```bash
npm install
npx wrangler dev
npx wrangler deploy
```

## Раздел администратора

- Доступ к разделу администратора защищён паролем (проверка в `src/index.js` через `/api/admin/login`).
- По умолчанию используется демо-пароль `astro-admin-2026`. Для продакшена на Cloudflare Workers задайте секрет:
  ```bash
  npx wrangler secret put ADMIN_PASSWORD
  ```
- В панели администратора доступны: публикация мероприятий и праздников (например, «День Здоровья»), ведение расписания занятий, просмотр 6-значного кода подтверждения и проверка заявок студентов.
- Для одного студенческого ID действует ограничение: не более **5 заявок в неделю**.
